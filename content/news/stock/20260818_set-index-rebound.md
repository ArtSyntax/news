ตลาดหุ้นไทยวันนี้ (18 ส.ค. 2026) ปิดตลาดในแดนบวกอย่างแข็งแกร่ง โดยดัชนี SET Index ปิดที่ระดับ 1,452.30 จุด ปรับตัวเพิ่มขึ้น 15.20 จุด หรือคิดเป็น +1.06% ด้วยมูลค่าการซื้อขายหนาแน่นกว่า 58,400 ล้านบาท ทะลุแนวต้านสำคัญที่ 1,450 จุดได้สำเร็จ

ปัจจัยหนุนหลักมาจากแรงซื้อเก็งกำไรในหุ้นกลุ่มขนาดใหญ่ (Big Cap) โดยเฉพาะกลุ่มธนาคารพาณิชย์และกลุ่มพลังงานที่ได้รับอานิสงส์จากราคาน้ำมันดิบในตลาดโลกที่ปรับตัวสูงขึ้นทะลุ 85 ดอลลาร์สหรัฐต่อบาร์เรล นอกจากนี้ ทิศทางเงินทุนต่างชาติ (Fund Flow) เริ่มส่งสัญญาณไหลกลับเข้ามาในตลาดหุ้นภูมิภาคเอเชีย

นักวิเคราะห์หลักทรัพย์จาก บล.เอเซีย พลัส ประเมินว่า แนวโน้มตลาดหุ้นไทยในสัปดาห์นี้ยังมีโอกาสแกว่งตัวขึ้น (Sideway Up) โดยให้กรอบแนวรับที่ 1,440 จุด และแนวต้านถัดไปที่ 1,465 จุด พร้อมแนะนำกลยุทธ์การลงทุนให้เลือกซื้อหุ้นที่มีปัจจัยพื้นฐานดีและผลประกอบการไตรมาส 3 มีแนวโน้มเติบโตโดดเด่น
